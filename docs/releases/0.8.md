# Atl-Atl: The Atltuner 0.8

This release replaces the screen with the pixel UI and adds battery charge.

## What is new

- **A pixel UI.** `assets/atl-atl-ui.png` is the at-rest screen. `assets/atl-atl-ui-on.png` supplies the active
  slices for LATCH, MASK, PLAY, LOOP, REC, sample presence, USB, charging and GLO. The app overlays only the slice
  whose state is on.
- **The BPM light pulses on the beat.** The BPM number stays in Geist Sans; every other value is Geist Mono.
- **Battery charge.** The battery icon gets a black fill inset by 3 px; 0% is the leftmost pixel column and 100% is
  the full inner width. The alternate battery slice is shown while USB power is present.
- **Centred text.** Every live value is vertically and horizontally centred in the slice boxes from
  `assets/atl-atl-ui.json`. Inactive text is `#cbdbfc`; active text is `#000000`.
- **The sample panel** shows its length, the computed loop note length, and the recorded root note.

The package is `atlatl-0.8.fwsc` for the 48 kHz codec. The firmware identity stays `FM-1_922`.
