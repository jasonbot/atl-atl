# Atl-Atl: The Atltuner 0.7

This release makes the sample playable from the keys and switches the large type to Geist Sans.

## What is new

- **GLO is play-note mode.** With GLO lit, every physical key or USB-MIDI note-on restarts the recorded sample and
  retunes it to that note. It plays once; the pitch stays at the triggered note after the key is released.
- **GLO and SEQ are exclusive.** Turning on GLO turns LOOP off; turning LOOP on turns GLO off. The mode is saved
  with SAVE.
- **The target note and BPM use Geist Sans.** The large values are now sans-serif; Geist Mono remains the small UI
  font. The unused Geist Serif face is gone.

The package is `atlatl-0.7.fwsc` for the 48 kHz codec. The firmware identity stays `FM-1_922`.
