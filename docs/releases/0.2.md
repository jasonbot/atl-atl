# Atl-Atl: The Atltuner 0.2

This release adds a sampler and makes tempo, the ARP mask, and MIDI keys work better. These are the changes since
release 0.1.

## What is new

- **Record a sound.** Hold **REC** to record up to 3 seconds of the computer's audio. The FM-1 keeps playing while
  it records. Silence at the start and end of the sample is cut off.
- **Play it back.** Press **PLAY** to play the sample once. Press **SEQ** to loop it. The loop length follows the
  tempo, so it stays in time. The sample plays together with the live tuned sound.
- **Set the tempo.** Turn **SELECT** to set 30–300 BPM. If the computer sends MIDI clock, the FM-1 follows that
  clock instead and shows `CLK` on the screen.
- **Quiet when no key is held.** Turn on **ARP** to mute the output until a key is held. **FX** keeps the note and
  the mask on after you let go.
- **MIDI keys now act like the FM-1 keys.** Hold more than one MIDI note: when you let one go, the FM-1 uses another
  note that is still held. MIDI note 0 works too. The ARP mask follows MIDI keys.
- **New screen rows.** `BPM`, `SAMPLE` and `MODE` show the tempo, the sample length, and whether the sample plays
  once or loops.
- **Saved settings.** Loop, mask and tempo are saved with **SAVE**.
- **A new test.** The host test checks recording, silence trimming, sample playback, MIDI held notes and the ARP
  mask.

The package is `atlatl-0.2.fwsc` for the 48 kHz codec. The firmware identity stays `FM-1_922`.
