# Atl-Atl: The Atltuner 0.4

This is a small fix over 0.3.

## What changed

- **Turning FX latch off now releases the last note.** Before, the FM-1 kept tuning to the old note after the latch
  was switched off. Now it goes back to the keys that are still held, or to the clean dry signal if none are held.
- **Latch and ARP off means forward.** With both off, the computer's audio passes through without the old tuner
  target keeping it shifted.

The sound engine and package identity are unchanged. The package is `atlatl-0.4.fwsc` for the 48 kHz codec.
