# Atl-Atl: The Atltuner 0.6

This release turns the sample into a playable one-note instrument.

## What is new

- **The sample is recorded unaltered.** REC captures the USB input before the tuner.
- **The keys pitch the sample.** The recorded note becomes the sample's root. Playing the sample while holding a key
  shifts it to that note, so one recorded note can be played up and down the keyboard. The sample still mixes with
  the live input.
- **Geist Serif now covers the target note and the BPM number.** Both use the large serif numerals and note letters;
  Geist Mono remains the small UI font. The leftover Terminus font files are gone.
- **Antialiasing is blended over the real background**, not just over black.

The package is `atlatl-0.6.fwsc` for the 48 kHz codec. The firmware identity stays `FM-1_922`.
