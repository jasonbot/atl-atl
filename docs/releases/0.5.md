# Atl-Atl: The Atltuner 0.5

This release changes the screen's type. The sound engine is unchanged.

## What is new

- **Geist Mono** is used for the small text: notes, pitch, sample, values and labels. Only printable ASCII is
  stored, since the UI no longer needs umlauts or other extended Latin characters.
- **Geist Serif** is used only for the BPM number. Only its ten numerals are stored, so the large font is small.
- **Real antialiasing.** The font data has 16 coverage levels, and the renderer now blends those levels over the
  actual background instead of assuming black. Text stays smooth on the light knob boxes and the note gradient.

The fonts are by Vercel, under the SIL Open Font License 1.1; the licence is in `LICENSES/OFL-Geist.txt`.

The package is `atlatl-0.5.fwsc` for the 48 kHz codec. The firmware identity stays `FM-1_922`.
