# Atl-Atl: The Atltuner 0.1

The first Atl-Atl release. The FM-1 is a USB audio sink and a key-targeted autotuner:

- hold a key to set the target note; the computer's audio is tuned to it and comes out of the speaker/headphones;
- KNOB1 SPEED, KNOB2 MIX, KNOB3 CORRECT, KNOB4 OCT; FX latches, EDIT toggles auto/fixed octave, SAVE stores;
- the USB sink is FM1_AudioBase's tested 48 kHz path, resampled to the codec's clock; the tuner DSP and UI came
  from the fm1-dock prototype;
- one app, no module picker, no OPTIONS page, no BLE-MIDI, no packaged synths.

Identity `FM-1_922`. Build from the tag with the JieLi toolchain; the package is `atlatl-0.1.fwsc`.
